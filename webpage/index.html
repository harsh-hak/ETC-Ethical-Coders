// HOW WE LEARN

Hands-On Learning Through Fun Puzzles

Capture The Flag (CTF) competitions are educational games where we find hidden clues by solving computer puzzles. As a team, we explore how websites work, crack secret codes, investigate digital files, and learn how to build safer software for everyone.
